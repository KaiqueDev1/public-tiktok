# Site público (Termos e Privacidade para o TikTok)

Antes de publicar, troque `kaiquedev.dev@gmail.com` pelo seu e-mail de contato nos 3 arquivos .html
(no VS Code: Ctrl+Shift+H, substituir em todos).

## Publicar no GitHub Pages (grátis)

1. Crie um repositório público no GitHub, por exemplo `resenha-corte-trecho`.
2. Envie os arquivos desta pasta (Add file → Upload files): index.html, termos.html, privacidade.html, style.css, logo.png, favicon.png.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, pasta `/ (root)` → Save.
4. Em ~1 minuto o site fica em `https://SEU-USUARIO.github.io/resenha-corte-trecho/`.
